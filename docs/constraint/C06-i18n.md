## 规则

### 当前实现

### Key 命名空间

- `panel.*` — 面板标题
- `container.*` / `image.*` / `volume.*` / `network.*` / `compose.*` — 资源级文案
- `container.<action>.form.*` — 表单字段、标题、required 提示
- `form.*` — 跨资源的表单通用文案(覆盖确认、路径补全提示)
- `hint.*` — 快捷键提示
- `key.*` — 按键符号(`key.sym_enter`, `key.confirm`, `key.cancel`)

### 缺失 key 回退

- 缺失 key 自动回退到英文(`en.jsonc`)
- 永不 panic
- 测试时建议显式断言 key 存在

### 终端宽度

- 中日韩字符按 `utils.DisplayWidth` 计 2 cells
- 表格 / Form / Dialog 列宽必须用可见宽度计算
- 短语避免硬编码列宽,优先用 `component.TruncateVisible`

### 文案约束

- Action Bar / Dialog 标题简短(< 24 字符)
- 错误 toast:简短动词 + 主语(< 80 字符)
- 帮助页:按动作归类,按键符号与 label 分两列

### 目标规范

与当前实现一致,无重大重构;待补内容:

- 命名空间层级粒度统一
- CI 检查缺失 key 与中英日一致性
- 文案长度限制的硬截断 / 软警告策略

## 文件

- `internal/data/i18n/lang/en.jsonc` — 英文(基准)
- `internal/data/i18n/lang/zh.jsonc` — 中文
- `internal/data/i18n/lang/ja.jsonc` — 日文

新增 key 必须同步三个文件。后续可加更多语言。
