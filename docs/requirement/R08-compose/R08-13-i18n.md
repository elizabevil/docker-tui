## 功能规则

### F1 i18n key 命名规范

按 [constraint/C06-i18n.md](../../constraint/C06-i18n.md) 第 2 节统一:

```text
compose.<scope>.<purpose>[.<modifier>]
```

scope 子空间:
- `compose.action.*` — Action Bar label / Command palette label
- `compose.dialog.*` — Confirm / Form / Detail dialog 文案
- `compose.toast.*` — toast 通知
- `compose.detail.*` — Detail 视图 label
- `compose.logs.*` — logs 视图标题
- `compose.events.*` — events filter 文案
- `compose.help.*` — Help 文本段落
- `compose.error.*` — 错误提示文本

### F3 zh.jsonc / ja.jsonc 占位

本需求**至少**确保 `en.jsonc` 全量;`zh.jsonc` / `ja.jsonc` 由 R13 后续批量翻译统一处理(不阻塞 R08-04..R08-12 落地),缺失时 fallback 英文。

### F4 翻译占位符

按 [docs/i18n.md §2](../../i18n.md):`{0}` / `{1}` / ...,数值用 `%d` 不行(必须走 strconv)。

### F5 CJK 宽度

按 C06:dialog 文案的预期宽度按 halfwidth 计数(`utils.DisplayWidth`)。

## R08-14 集成

R08-14 横切新增 i18n 命名空间 `compose.co_located.*`(详见 [R08-14 §I7](./R08-14-co-located-group.md)):

```text
compose.co_located.group_label         "Co-Located Group"  (UI 折叠标签默认显示)
compose.co_located.group_members       "Members: {0}"     (services list 展开显示)
compose.co_located.no_group            ""                  (空 group 时不显示)
compose.co_located.source_docker_network_mode   "(shared network)"
compose.co_located.source_podman_default        "(project pod)"
compose.co_located.source_unrecognized          "(ungrouped)"
compose.co_located.scale_blocked_docker         "Scaling blocked: Docker compose network_mode: service: requires replicas=1"
compose.co_located.group_down_toast_ok          "✓ down group {0} ({1} services)"
compose.co_located.group_restart_toast_ok       "✓ restart group {0} ({1} services)"
compose.co_located.group_exec_toast_started     "→ exec on {project}/{group}/{container}"
```

命名空间前缀遵循 R08-13 §F1 规则(`compose.<scope>.*`) + 新增 scope = `co_located`。
