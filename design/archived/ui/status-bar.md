# Status Bar — 底部状态栏

## 状态

- [x] 已实现 (常驻显示)

## 布局

```
┌──────────────────────────────────────────────────────────────────┐
│  ● podman │ 5 containers │ 3 marked │ Error: connection refused  │
└──────────────────────────────────────────────────────────────────┘
```

## 字段

| 字段 | 条件 | 样式 |
|---|---|---|
| `● podman` | 已连接 | 绿色引擎名 |
| `● disconnected` | 未连接 | 红色 |
| `│ 5 containers` | 始终 | 默认 |
| `│ 3 marked` | 有标记项 | 黄色高亮 |
| `│ Error: ...` | 有错误 | 红色 |

## 样式

- 背景: 主题 Surface 色
- 前景: 白色
- 高度: 1 行
