# Detail Panel — 右侧详情面板 (已废弃)

## 状态

- [x] **已废弃** — 替换为全屏详情视图 (`container-detail.md`, `image-detail.md`)

## 废弃原因

- 右侧分栏占用主表格空间
- 信息展示受限 (小区域难以展示完整 inspect 信息)
- 交互不一致 (容器/镜像/卷/网络的详情入口不同)

## 新方案

| 资源 | 旧入口 | 新入口 |
|---|---|---|
| 容器详情 | 右侧面板自动显示 | `d` → 全屏详情 |
| 镜像详情 | `Enter` | `d` → 全屏详情 |
| 镜像容器列表 | — | `Enter` → 容器列表 |
| 容器日志 | `l` | `l` → 全屏日志 (不变) |

> 统一规则: **所有表格 `d` = Detail 详细信息，`Enter` = 关联资源**
>
> ---
>
> 以下为原设计文档，仅供参考。

## 显示条件

- 终端宽度 ≥ 80 列 (Dual/Triple 模式)
- 有选中的容器

## 三栏模式 (≥120列)

```
右列 = 40% 屏幕宽度
├── 上半: Detail (40%)  ─── ID/Name/Image/State/Ports
└── 下半: Logs   (60%)  ─── 最近 10 行日志预览
```

## 双栏模式 (80-119列)

```
右列 = 40% 屏幕宽度
└── 全高: Detail  ─── ID/Name/Image/State/Ports/Stats
```

## 详情面板内容

```
┌──────────────────────────────┐
│  Detail                      │
│                              │
│  ID:    abc123def456         │
│  Name:  web-app              │
│  Image: nginx:latest         │
│  State: running              │  ← 彩色显示
│  Status: Up 2 hours          │
│  Ports: 0.0.0.0:8080->80/tcp │
│  Compose: myapp/web           │  ← 有 Compose 标签时显示
│  CPU:   12.5%  MEM: 45.2%    │  ← Stats 开启时显示
└──────────────────────────────┘
```

## 日志预览面板 (三栏模式)

```
┌──────────────────────────────┐
│  Logs                        │
│                              │
│  2024-01-15T10:00:00 GET /   │
│  2024-01-15T10:00:01 200 OK  │
│  2024-01-15T10:00:02 POST .. │
│  ...                         │
└──────────────────────────────┘
```

- 显示最近 10 行
- 按 `l` 进入全屏日志视图
- 选择容器后自动更新
